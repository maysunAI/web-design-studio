# Web Design Studio

A small, dependency-free library of web design building blocks: 29 color themes, 35 SVG backgrounds, 4 live canvas backgrounds (sky, rain, sea, snow), 12 multi-column page templates, and a drag-and-drop image maker. Everything is original and generated by the scripts in `tools/`.

## Use
Open `index.html` in a browser (or serve the folder with any static server). Pick a theme, a background, then a template; the copy button gives you a line like "theme 12 + background 07".
Templates take `?theme=12&bg=07` in the URL.

## Layout
- `css/` tokens, themes, backgrounds, layout, motion
- `js/` catalog, theme switcher, live backgrounds, templates list
- `templates/` 12 page templates
- `bg/` 35 SVG backgrounds
- `tools/` Python generators for backgrounds/templates
- `maker.html` image maker (the AI buttons need a server and are inactive here)
